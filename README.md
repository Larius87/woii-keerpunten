# AI-geletterdheid voor leerkrachten

Deze repository bevat de website als een zelfstandige statische pagina:

- **Websitebestand:** `index.html`
- **Geen buildstap nodig:** open `index.html` rechtstreeks in een browser of serveer de map lokaal.

## Lokaal bekijken

Vanuit de repositorymap:

```bash
python3 -m http.server 4173
```

Open daarna:

```text
http://localhost:4173/
```

## Wat staat op de site?

- Een startpagina met de bootjesmetafoor: “Wanneer laten we AI aan land?”
- Een visuele weergave van het NPULS AI-GO-model voor AI-geletterdheid.
- Een workshop/draaiboekpagina voor de personeelsvorming van ongeveer 3u30.
- Een interactieve presentatiepagina met vorige/volgende slides.
- Werkmateriaal: fiche-set, KIES-prompt en LAB AI-schaal.
- Een korte bronnen- en beleidsverankeringssectie.

## Publiceren

Omdat de site uit één `index.html` bestaat, kan ze rechtstreeks gepubliceerd worden via bijvoorbeeld GitHub Pages, Netlify, Vercel of elke statische webserver.
